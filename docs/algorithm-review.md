# v8/v9 算法审查

## 结论

当前实现的主体方向是合理的：离线场景使用分块对齐、Side 控制信号、复数
传递函数和参考引导的后级抑制，比单纯功率谱减更适合真实同源媒体。原实现
的主要短板不在 STFT 本身，而在时间模型和状态恢复：

- 全局扫描始终围绕首个 offset 跟踪，超过局部搜索半径的暂停、跳转和重放
  无法可靠恢复。
- 每个处理块只使用一个固定采样偏移，无法相消小幅变速和速度抖动。
- Side 低相关区间统一从相邻窗口插值，会把真实暂停误判成“继续播放”。
- 四个强度参数缺少统一、稳定的产品语义。

本轮已经分别用“失锁后限频全局重获”“250ms 局部时间扭曲”“低能量暂停
门控”和开放刻度 `strength` 修复这些问题。

后续实验又加入了验证式双分辨率对齐：250ms 路径检测到可信漂移时，生成
16ms 候选；只有候选保持单调、边界合法，并同时改善留出窗口的中位相关性、
不损害低分位相关性时才采用。

## 当前能力边界

| 场景 | 当前处理 |
| --- | --- |
| 平滑或突变音量 | 250ms/50ms 的 Side 增益包络 |
| 暂停、续播 | 暂停区间将参考增益归零；扫描失锁后重获 |
| 跳转、重放 | 重获后建立新的 offset 分段 |
| 4–24 小时输入 | 流式指纹索引召回候选，不建立完整波形 FFT |
| 媒体截断 | 无高置信匹配时透传 |
| 小幅左右平衡变化 | 复数 Mid/Side 传递函数可吸收小幅变化 |
| 稳态小幅变速 | 分段 offset slope + 块内局部时间扭曲 |
| 低频速度抖动 | 250ms 锚点的采样级分段重映射 |
| Mono/stereo 输入组合 | 按原始混合输入声道数路由和输出；参考 mono 时保留混合 Side |

仍未完全解决：

- 大幅、快速、非线性变速，尤其一个 250ms 窗口内已经明显漂移。
- 参考或混合经过强动态压缩、限幅、非线性失真。
- 大幅左右平衡变化会产生 Mid/Side 交叉耦合；当前模型不是完整 2×2 传递
  矩阵。
- 主播与媒体中高度相似、同时居中的人声属于不可辨识的 double-talk，
  只能依赖保护策略和后续 ASR 验收取舍。

## 更进一步的算法候选

### 1. 带跳转状态的 banded online DTW

用 log-mel/CQT 特征维护窄带 DTW 路径，并加入 pause、replay、seek 的跳转
状态，能把“发现分段”和“块内速度轨迹”合成一个时间模型。它比当前相关
锚点更适合大幅 tempo drift，但实现、内存和错误路径恢复都更复杂。当前
分层方案是风险较低的中间态。

参考：

- [Real-Time Audio-to-Score Alignment of Music Performances Containing Errors and Arbitrary Repeats and Skips](https://arxiv.org/abs/1512.07748)
- [Exact, Parallelizable Dynamic Time Warping Alignment with Linear Memory](https://arxiv.org/abs/2008.02734)

### 2. 分区频域自适应滤波器（MDF/PBFDAF）

当前复数传递函数本质上是块内平滑最小二乘。MDF/PBFDAF 加受控学习率和
double-talk gating 后，能更连续地跟踪 EQ、声道和编解码路径变化，也避免
每块重新估计。代价是状态管理、收敛/重收敛调参和主播 double-talk 导致的
滤波器偏置。适合作为下一版 A/B 分支，不宜无基准替换现有离线路径。

参考：

- [A New Robust Frequency Domain Echo Canceller with Closed-Loop Learning Rate Adaptation](https://jmvalin.ca/papers/valin_icassp2007.pdf)
- [Robust Extended Multidelay Filter and Double-Talk Detector for Acoustic Echo Cancellation](https://www.buchner-net.com/lnt2006_10.pdf)

### 3. 2×2 Mid/Side 传递矩阵

同时估计 `mix_mid <- ref_mid, ref_side` 和
`mix_side <- ref_mid, ref_side`，可显式处理 balance/pan 造成的交叉耦合。
这是比完整 MDF 更小的一步，但矩阵病态时必须做正则化，并在主播 double-talk
期间冻结或降低 Mid 相关分量的可信度。

### 4. ASR 驱动的强度校准

`strength` 不应只按残留 RMS 选择。生产扫描应至少同时记录：

- 主播重叠语句召回；
- 媒体-only 错误字幕；
- 主播低语/短语气词召回；
- 人声分离后媒体 vocal stem 能量；
- 听感或感知质量诊断。

当前开放刻度中 `0` 为保真优先、`1` 为 v8 激进档，`>1` 延续 v9 的
ASR 导向清理。高于 2 允许实验，但必须用上述指标决定是否值得。

## 实验结论：双分辨率与 2×2 Side-MIMO

8 个随机种子的合成对齐基准中，验证式 16ms 候选得到：

| 场景 | 250ms 中位误差 | 自适应中位误差 | 候选接受 |
| --- | ---: | ---: | ---: |
| `0.5%` 稳态变速 | 0.170 | 0.025 | 8/8 |
| `1%` 稳态变速 | 0.547 | 0.027 | 7/8 |
| 慢抖动 3 samples | 0.108 | 0.032 | 7/8 |
| 慢抖动 10 samples | 0.217 | 0.027 | 8/8 |
| 慢抖动 30 samples | 0.537 | 0.028 | 8/8 |
| 250ms 快抖动 3 samples | 0.595 | 0.090 | 8/8 |
| 250ms 快抖动 10 samples | 0.992 | 0.235 | 8/8 |
| 250ms 快抖动 30 samples | 1.281 | 1.281 | 0/8 |

把真实 `sr.webm` 人为加速 `0.5%` 并叠加独立前景后，误差从 0.797 降到
0.090。8ms 候选对最快抖动更强，但在真实媒体上略退化且更容易出现短窗
歧义，因此最终选择 16ms。

进一步把该变速媒体以动态音量混入真实前景，完整相消后的目标相对误差从
0.229（-12.82dB）降到 0.073（-22.70dB），改善约 9.9dB；Side 残留比从
0.327 降到 0.128。检测到漂移的 15 秒块中，对齐耗时约从 0.30 秒增加到
1.20 秒；未触发候选的普通块不承担短锚点开销。

现有真实五段中四段没有触发候选，一段生成候选但因留出分数下降被拒绝；
最终输出与纯 250ms 版本逐样本一致。

2×2 Side-MIMO 原型能明显降低 Side 建模误差，但最终 Mid 目标收益很小：
大 balance 的中位收益约 0.225dB，左右不同 FIR 约 0.065dB，double-talk
时必须完全回退。因此暂不引入生产路径。

## 实验结论：其他相消器

后续实验固定正确对齐，只比较传递路径估计和相消方法。评估同时分解前景
增益、线性媒体泄漏和非相干误差，避免把“保留了更多不相关前景”误判为
媒体残留。

### MDF/PBFDAF

从 Side 学习一个公共 L/R FIR、再迁移到 Mid 的 PBFDAF 在稳定合成 FIR
路径上很强，但该公共路径假设不适合现有真实双重编码素材：

- 稳定合成 FIR 的相消分数可从约 26.6dB 提高到 62.5dB；
- 路径切换约提高 0.6dB，持续 Side double-talk 约提高 0.7dB；
- 动态音量和软限幅分别落后约 1dB 和 3.5dB；
- 真实五段的总 Side 残留高约 1.6–2.4dB，而且残留中可由参考解释的
  比例由当前约 7%–10% 上升到约 29%–40%。块长、滤波器长度、学习率
  和 double-talk 门控扫描没有改变这一结论。

标准的直接 `reference Mid -> mixture Mid` MDF 即使降低学习率，最佳合成
分数也只有约 13.6dB，明显低于当前约 26.6dB；主要问题是 double-talk
下的滤波器失调噪声，而不是简单的整体前景增益损失。完整 closed-loop
学习率或 Kalman 版本仍可另立实验，但当前原型不进入生产路径。

### 鲁棒与多尺度 Wiener

三轮 Huber/IRLS 传递函数只在固定 FIR 上提高约 0.36dB，在路径切换、
软限幅和 double-talk 上均略退，不足以抵偿计算成本。

只把 Mid 传递函数的时间平滑由约 10 帧延长到 30 帧，在稳定路径和持续
double-talk 上可改善约 4dB；但无条件使用会在真实节目构造的路径切换中
退化约 2.4dB。用长短 Mid/Side 传递函数的分歧比做保守门控后，16 个
随机种子的动态增益和路径切换没有回退，软限幅中位改善约 0.37dB；不过
现有真实五段均未触发，因此暂时保留为专项候选，不增加默认路径复杂度。

### 相位敏感/Wiener 掩码

把当前媒体预测改成相位敏感或功率 Wiener 掩码，会直接衰减与媒体重叠的
主播频点。真值测试中综合分数从当前约 15–27dB 降到约 8–14dB，前景
衰减扩大到约 0.2–1.0dB，因此不适合同源、已精确对齐的参考相消。

### 标量快路径判定

实验同时发现一个独立缺陷：原代码以“复数传递函数拟合后的 Side 误差”
判断是否可退回时域标量相减。非平凡 FIR/EQ 也能被复数模型很好拟合，
因此会错误丢弃已估计的滤波路径。现在改为直接检查标量增益模型本身的
Side 误差；已知 FIR 的合成相消分数由约 21.5dB 提高到 26.6dB。

## 实验结论：块级 offset momentum 与消除后验证

真实素材 `miyako.webm` / `sr.webm` 的一次完整消除中，`_align_reference()`
在 375–405 秒和 2845–2875 秒两处抛出 `Aligned reference does not cover the
complete chunk`，直接终止全任务，只能手工 monkey patch 成透传。

复现该块后可以确认根因不是匹配失败：

| 块（context 起点） | 先验误差 | 覆盖缺口 | 半径 0.25s | 半径 1.49s |
| --- | ---: | ---: | --- | --- |
| 2844s | +0.000s | 0.490s | 未覆盖，抛异常 | align 0.848，消除 7.17dB |
| 374s | +0.000s | — | 未覆盖，抛异常 | align 0.886，消除 6.28dB |
| 384s | +0.000s | — | 未覆盖，抛异常 | align 0.868，消除 6.99dB |

分段 offset 完全正确（先验误差 0.000s），但块内自适应时间扭曲需要比
`±search_sec` 窗口多出约 0.49 秒的参考——32 秒块上约 1.5% 的速度差。
窗口不够长是可恢复条件，因此改为返回覆盖状态并上报缺口，由调用方按
`deficit + 4 * search_sec` 扩窗重试一次。

同一区间的 4 kHz momentum 探测（2785–2905 秒，步进 30 秒）给出的
offset 与分段模型偏差均为 0.000s，分数 0.43–0.62。也就是说 momentum 在
这一处并不改变 offset，它的价值在于两点：长分段非线性漂移的跟踪，以及
为逐块表决提供一个与块内相关分数相互独立的证据。

表决设计中途做过一次修正。最初把"对齐结果是否落在预测附近"当作一票，
但粗对齐被先验约束后，落在预测附近几乎必然成立，该票退化为常真。改为：

- 偏离预测超过容差 → 一票否决（约束只影响"是否靠近"，不影响"是否跑飞"）；
- 三票分别为块内相关分数、momentum 探测置信度、实测控制通道能量下降；
- 相关分数 ≥ 0.60 单独计两票，保持原有"强相关直接处理"的行为。

实测能量下降（标量增益路径，无 STFT）是其中最便宜也最难被伪造的一项：
错误对齐时它稳定为 +0.0dB，正确对齐时为 +7dB 以上。

### 完整复跑结果

改动后按 `--start 375 --end 4613`、`--strength 1 --workers 4` 重跑同一素材
（只写重叠区间 375–4613 秒）：

| 指标 | 结果 |
| --- | --- |
| 块处理结果 | 142/142 全部消除，0 块低置信度透传 |
| 扩窗重试 | 0 块触发 |
| 对齐分数 | 中位 0.826，最低 0.528 |
| 实测能量下降 | 中位 +6.12dB，范围 +1.73 ~ +12.62dB |
| 16ms 候选 | 20 块生成候选，全部被验证拒绝（与旧版一致） |
| 耗时 | 4238 秒输出用时 279.5 秒（RTF 0.066） |

对照上一轮：同素材需要手工 monkey patch 才能跑完，2845–2875 秒被降级为
透传。本轮该区间（2835–2865 秒块）align 0.828、下降 7.11dB 正常消除，且
未触发重试——momentum 逐块修正后，块内对齐始终留在 ±0.25 秒窗口内，扩窗
重试成为纯兜底路径。

扫描侧两段的 `traj-dev` 均为 0ms，即该素材 offset 在 3320 秒内完全稳定。
轨迹化对本素材是零收益的保险，真正修复 2845 的是覆盖状态 + momentum。

3075 秒块是表决机制的典型样本：align 0.528 低于强相关阈值，但实测下降
+1.73dB，靠「相关分数一票 + 能量下降一票」通过。旧的 `align < 0.20 透传`
门限同样会放行它，区别在于旧门限无法区分它与真正的错误对齐——后者的实测
下降稳定为 +0.0dB。

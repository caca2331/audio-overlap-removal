# 迭代式参考音频消除：探索记录

本文记录一次尚未进入正式实现的算法探索。目的不是为某组参数背书，而是保留从问题建模、失败反例到当前候选方案的完整推理链。

相关可复现实验与指标快照位于
`experiments/iterative-cancellation/`。正式 CLI、流水线和默认输出均未修改。

## 1. 起点：能否修补第一遍实际减掉的媒体

设：

- `C = A + B'`：混合音频；
- `A`：希望保留的前景；
- `B`：原始媒体参考；
- `B'`：经过播放、采集、EQ、增益变化等路径后的实际媒体；
- 第一遍输出 `A'`；
- 第一遍估计的媒体 `B'' = C - A'`。

最初设想是比较 `B''` 与 `B`，修补得到更接近 `B'` 的 `B'''`，再计算
`A'' = C - B'''`。

第一个关键修正是：不能从最终 `strength=1` 输出计算 `B''`。最终输出包含非线性频谱清理；`C - A'` 会同时包含线性媒体预测和清理掉的前景成分。若用它训练下一遍，下一遍会把第一遍对 `A` 的损伤当作媒体继续学习。

因此实验始终把“路径建模”和“最终清理”分开：

1. 在线性、无清理的中间点取得媒体预测；
2. 只修补该预测；
3. 最终清理最多执行一次。

## 2. 第一种假设：从残差中再估计一次参考路径

直接从 Mid 残差拟合参考风险较高，因为人声通常也在 Mid。第一版原型优先使用相对前景安全的 Side：

1. 第一遍得到 Mid/Side 残差；
2. 从 Side 残差与参考 Side 估计剩余传递函数；
3. 将该函数应用到参考 Mid；
4. 修正量限制为第一遍预测的 25%；
5. 只做一轮。

合成 moving-gain 场景从 25.91 dB 提升到 28.10 dB，双讲和纯人声场景没有可测退化。固定 FIR、路径突变、左右不对称和软削波基本没有收益。

这个结果说明该方法能修补时间变化的线性路径误差，但不是通用的“第二遍增强”。

## 3. 非线性支路：软削波

为处理软削波，实验从 Side 残差拟合三次和五次奇次项，并用交替的一秒分块做交叉验证。它在合成软削波上有约 0.54 dB 线性阶段收益，但进入完整 `strength=1` 输出后只剩约 0.14 dB。

真实三段素材均未通过非线性门控。收益不足以承担额外模型和误判面，因此该支路被放弃。

## 4. `strength=0` 与更保守的第一遍

`strength=0` 会关闭频谱清理，但当前线性模型仍使用 Mid 相关性；它并不等于“完全不会吸收 A”。

实验比较了：

- 当前无清理线性模型；
- 完全不使用 mixture Mid 学习传递函数的 Side-only 模型；
- 后者再执行最多六次 Side 残差修补。

Side-only 模型把合成前景系数偏差从约 -0.06 至 -0.13 dB 改善到接近 0 dB，但路径突变、左右不对称和软削波的消除能力明显下降。它更安全，却不是完整模型的替代品。

## 5. 多轮循环是否有价值

从当前无清理线性模型开始重复 Side 修补，moving-gain 的结果为：

| 阶段 | 抑制 |
|---|---:|
| 初始 | 25.91 dB |
| 第 1 轮 | 28.10 dB |
| 第 2 轮 | 28.22 dB |
| 第 3 轮 | 28.25 dB |
| 第 6 轮 | 28.29 dB |

真实 middle 片段的 Side 残差改善依次约为 0.61%、0.20%、0.11%、0.08%、0.06%、0.04%。

重复相同估计器本质上接近 boosting：第一轮获取主要收益，之后逐渐追逐更小、也更可能属于前景或噪声的成分。因此不采用固定 3/4 轮，更不采用无上限循环。候选停止条件为：

- 最多两轮；
- 本轮 Side 改善低于约 0.15% 时停止；
- 或 Mid 修正低于输出 RMS 的约 0.1% 时停止。

## 6. 第一次端到端纠错：不能破坏 fast path

早期真实 A/B 将修正近似叠加到已经清理的输出，middle 的参考相关残留代理下降约 11.8%。这不是严格结果，因为修正后没有重新计算清理掩码。

严格原型改为：

1. 无清理线性预测；
2. 0–2 次 Side 修补；
3. 根据修正后的预测重新计算一次清理。

第一版严格原型反而把 moving-gain 从 25.91 dB 降到 19.55 dB，并造成约 -0.25 dB 前景偏差。原因不是循环，而是当前实现对近似精确数字混音会提前返回并跳过全部清理；原型错误地在循环后强行清理。

保留 early-return 语义后：

- moving-gain：25.91 → 28.22 dB，前景不变；
- 其余八个合成场景均未触发，直接保留当前输出；
- 真实 middle 触发两轮，但严格重算清理后的参考相关残留只改善约 0.59%，输出变化约 0.43% RMS。

这解释了为什么监听差异很小，也否定了先前对 11.8% 近似指标的乐观解读。

## 7. 双模型假设：`B_safe` 与 `B_full`

下一步同时计算：

- `B_safe`：只从 Side 和标量增益得到的保守预测；
- `B_full`：当前完整线性预测；
- `D = B_full - B_safe`：可能包含重要 Mid 路径，也可能包含被误吸收的前景。

最初尝试只在保守残差仍与参考高度一致、且媒体能量占优时放行 `D`。低保留比例在合成测试上看似更好，却在真实素材上失败：`D` 占 `B_full` 预测 RMS 的 39%–59%，说明真实录制的 Mid 专属路径是主体信息，而不是可以轻易丢弃的小尾巴。低门控令参考相关残留大幅上升。

随后搜索 `B_full` 的最低保留比例。90% 是当前观察到的折中点：

| 合成场景 | 当前 | 双模型 90% floor |
|---|---:|---:|
| common FIR | 19.01 | 19.21 dB |
| path switch | 17.91 | 18.15 dB |
| soft clip | 14.51 | 14.60 dB |
| asymmetric L/R | 13.74 | 13.80 dB |
| side double-talk | 18.12 | 18.32 dB |
| music double-talk | 20.34 | 20.51 dB |

扩展的 11 个合成真值场景全部持平或小幅改善，前景系数持平或略有改善。

真实 early/middle/late 的输出变化分别约为 0.82%、1.12%、1.82% RMS；保守参考相关残留代理分别下降约 9.2%、0.5%、2.2%。early 的绝对残留本来极小，较大的相对百分比不应解读为明显听感收益。

## 8. 当前结论

现阶段最有希望的研究候选是分路径组合，而不是统一多轮循环：

1. 保留现有数字混音 fast path；
2. fast path 中允许门控的 0–2 次 Side 残差修补；
3. 其他路径使用至少 90% 的 `B_full`，仅小幅向 `B_safe` 收缩；
4. 最终清理只执行一次；
5. 所有门控拒绝时直接走当前路径，避免无意义的 STFT 往返。

但真实素材收益仍小，尚不足以进入默认生产路径。继续推进前最需要的不是更多迭代轮数，而是更多带已知前景真值的真实传递路径数据，以及对耳语、媒体人声和强双讲的盲听。

## 9. 未证明的事项

- 90% floor 不是普适最优值，只是当前素材上的稳定折中。
- 参考相关残留代理不能替代前景真值，也不能单独证明听感更好。
- 合成测试覆盖了若干典型路径，但没有覆盖所有设备非线性和时变失真。
- 实验代码为了可读性重复了部分清理逻辑；若进入正式实现，应先拆分“预测”和“清理”内部接口，而不是复制生产 DSP。
